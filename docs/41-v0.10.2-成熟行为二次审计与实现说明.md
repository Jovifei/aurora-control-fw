# v0.10.2 成熟行为二次审计与实现说明

## 1. 版本目标

本版本在 v0.9.1 基础上补齐第二轮 120W 成熟行为对照中确认的软件缺口，并保持所有物理功率门禁关闭。

固件版本：

```c
AURORA_FW_VERSION_MAJOR = 0
AURORA_FW_VERSION_MINOR = 10
AURORA_FW_VERSION_PATCH = 2
```

## 2. 已实现的软件行为

- 三元锂、磷酸铁锂：0°C 以下禁止充电，+5°C 恢复；
- 铅酸、钠离子：-20°C 以下禁止充电，-15°C 恢复；
- 最大充电时间与浮充时间只在实际功率传输时累计；
- PV_I 使用 AVDD/2 中点模型，名义零点为 2048，并保留启动运行时零点质量校准；
- BST_U 近满量程拒绝继电器判据，并增加相对 BAT_U 过冲与绝对母线过压检查；
- 启动失败按零点、弱光、母线预升压、Relay 复核、电池稳定等原因分类；
- 零点、预升压、Relay 和电池稳定失败采用有限重试；严重 BUS 过压直接锁存；
- LED 与旧协议增加新故障映射及未知非零故障兜底；
- Flash Journal 升级为 v3，兼容读取 v1/v2；
- 增加 PV 实测能量与电池侧估算充电能量两套统计；
- 增加受限 Demo 无电池带载模式。

## 3. 不等价或不迁移项

- 新板没有 BAT_I 独立 ADC，电池电流仍为估算值；
- 不伪造电池反向电流检测能力；
- 新板为异步 Boost，不恢复旧同步 Q5 控制；
- 新板没有旧 Q9/Q11 软接通路径，防拉弧目标由 BST_U 母线预升压和 Relay 均压替代；
- 当前 PCB 没有与旧 120W BAT 硬件 OVP 完全等价的独立比较器链；
- OTA/IAP 不在本版本范围内。

## 4. 仍需硬件闭环

- BST_U 26:1 分压在高压档存在量程不足；
- PV_I 零点、增益、极性、温漂和 OPA 线性必须实板标定；
- COMP → Break → PWM → U6 EN → 实际 Vgs 必须示波器验收；
- Relay 吸合压差与触点拉弧必须实测；
- Demo 空载、纯电容、电子负载、短路和外部有源电压必须台架验收。

## 5. 发布边界

以下门禁保持 0：

```c
BOARD_GATE_COMP_ROUTE_VALIDATED
BOARD_GATE_ANALOG_CALIBRATED
BOARD_GATE_KEIL_LINKED
BOARD_GATE_LOW_VOLTAGE_BENCH
BOARD_GATE_DEMO_LOAD_VALIDATED
BOARD_POWER_OUTPUT_ALLOWED
```

因此本版本是软件候选基线，不代表 300W 实功率已经放行。
