# 10 · 旧工程迁移对照

仓库不保留旧MCU工程、历史厂商源码、闭源MPPT库或重复SDK示例，只保留必要的行为对照：

| 旧实现 | 当前实现 |
|---|---|
| `Fun_Get_ADC_Value`同时采样、换算、PWM门控、保护、累计并置10ms标志 | ATMR触发ADC+DMA；measurement只计算；保护、MPPT、充电、PWM分离 |
| 50 kHz ISR阻塞等待ADC | ADC硬件触发+DMA；ISR只发布半块或错误 |
| 闭源MPPT库直接输出Duty | 自研P-V斜率搜索输出Vpv_ref，PI输出功率，执行器转物理Duty |
| 同步互补Boost | 单路GLC异步Boost，放能使用二极管，不存在高侧同步状态 |
| BAT_I实测 | 由PV功率与BAT_U估算，质量明确标记ESTIMATED |
| 外部/模拟EEPROM语义 | 片内Flash双页CRC日志 |
| 共享10ms标志驱动多个任务 | 各模块使用时间戳独立调度 |
| 多处直接切AF/MOE恢复PWM | Service唯一正常出口，故障ISR只关断，epoch阻断旧命令 |

保留旧UART协议是行为兼容要求，不等于保留旧源码。当前协议实现仅在`app/protocol.c`，不存在`legacy_protocol_import`或`arm_*`文件。
