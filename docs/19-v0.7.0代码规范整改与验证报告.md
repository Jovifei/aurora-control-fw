# 19 · v0.7.0 代码规范整改与验证报告

## 1. 整改内容

- APP目录改为 `app/inc/*.h` 与 `app/src/*.c`；CMake和Keil工程同步更新；
- 9个APP模块、Board、Driver、Service、Keil入口/中断和Host测试的函数定义统一使用 `Name/Input/Output/Description` 头注释；
- 条件判断、状态转移、故障关断、预充、MPPT、Flash提交、看门狗和ISR事件桥接增加必要逻辑注释；
- 统一4空格缩进，禁止Tab和行尾空白；
- 所有文件级 `static` 定义集中在首个公开函数之前；
- 应用算法参数集中到 `app/inc/app_config.h`，板级参数集中到 `board/board_config.h`；
- 头文件宏补充用途和单位说明；
- 存储页偏移、协议动作/资源、UART缓冲、ADC超时、IWDT时钟等魔法数改为具名常量；
- 新增 `tools/check_code_style.py`，防止后续提交破坏上述规则；
- 新增故障后重新授权必须从零Duty/零积分起步的Host回归。

## 2. 安全相关修正

- `abs_i32(INT32_MIN)`改为饱和返回，避免有符号溢出；
- 设置变更会重置Charger、MPPT和Power Stage，撤销旧档案下的功率命令；
- 故障、OFF和WAIT_BATTERY路径统一清零Duty与功率积分；
- Service首次授权仍执行：关波→零CCR preload→自然UPDATE确认→安全epoch/Break/板级总门复核→放行；
- Flash只在PWM关闭且继电器断开时执行，并最后单独写Commit Marker；
- 功率总门保持0。

- 目标板PinMux、ADC原始码、OPA零点、温度标定；
- COMP0_O→U6 EN→ATMR Break强制触发；
