# 06 · 充电状态机与电池档案

## 1. 12组电池档案矩阵

`app/src/charger.c` 集中保存 4 种化学体系 $\times$ 48/60/72V 三种平台共 12 组只读档案：

| 化学体系 | 48V CV (mV) | 60V CV (mV) | 72V CV (mV) | Float 阶段 | 低温禁充/恢复 |
|---|---:|---:|---:|---|---|
| **铅酸 (Lead-Acid)** | 58,000 | 72,500 | 87,000 | 有 (54.6 / 68.3 / 82.0V) | -20°C / -15°C |
| **三元锂 (Ternary)** | 54,600 | 71,400 | 84,000 | 无 (直接 Complete) | **0°C / +5°C** |
| **磷酸铁锂 (LFP)** | 57,600 | 72,000 | 86,400 | 无 (直接 Complete) | **0°C / +5°C** |
| **钠离子 (Sodium)** | 56,100 | 72,600 | 85,800 | 无 (直接 Complete) | -20°C / -15°C |

## 2. 状态机与转移条件

```text
OFF → TRICKLE → CC → CV → FLOAT(仅铅酸) → COMPLETE
                   ↑   │                     │ (低压1s)
                   └───┘ (低压12s)           ↓
                         └──────────────→ RECHARGE
```

### 转移时序：

1. **OFF $\rightarrow$ TRICKLE / CC**：
   - $V_{bat} < V_{trickle\_exit}$ 时进入 TRICKLE（涓流）；
   - $V_{bat} \ge V_{trickle\_exit}$ 时直接进入 CC（恒流）。
2. **TRICKLE $\rightarrow$ CC**：
   - $V_{bat} \ge V_{trickle\_exit}$ 连续稳定 **110ms**（`AURORA_TRICKLE_TO_CC_HOLD_MS`）。
3. **CC $\rightarrow$ CV**（加权积分机制）：
   - $V_{bat} \ge V_{cv\_target}$ 时加权计分（基础 +1 分，越压 100mV 额外 +1 分，越压 200mV 额外 +4 分）；
   - 累计积分 **> 10 分**（严格大于阈值 `AURORA_CC_TO_CV_SCORE_THRESHOLD`）进入 CV；
   - 切换瞬间将当前前馈功率作为 CV 积分初值（暖启动），避免欠驱拉低电压。
4. **CV $\rightarrow$ CC**（控制稳定回退门）：
   - $V_{bat} < V_{cv\_target} - 500\text{mV}$ 持续 **110ms**；
   - **且必须同时满足**：`!weak_light && !thermal_limited && !input_limited`，防止云影或限温时误判回退。
5. **CV $\rightarrow$ Float / Complete**（尾流判满）：
   - 电压在 $[V_{cv\_min}, V_{cv\_max}]$ 窗口内，且 $I_{bat\_est} \le I_{tail}$（约 300mA）持续 **1s**（`AURORA_TAIL_HOLD_MS`）；
   - 弱光（$P_{pv} < 3\text{W}$）、温度降额或输入功率受限时暂停判满；
   - 铅酸进入 Float，其余三类化学体系直接进入 Complete。
6. **CV $\rightarrow$ Float 过程（铅酸专属）**：
   - 进入 Float 时先暂停功率传输，等待电池电压自然回落到 Float 窗口中点 $[(V_{float\_min} + V_{float\_max})/2]$ 并保持 110ms，再开启 Float PI 控制；
   - **低压回退**：浮充中 $V_{bat} < V_{float\_min}$ 持续 **12s**，请求 `request_restart`，经电池稳定准入重新进入 CC；
   - **低流结束**：浮充电流 $I_{bat\_est} \le 80\text{mA}$ 持续 **60s** 进入 Complete；
   - **浮充总限时**：累计真实传输时间满 **180min** 进入 Complete。
7. **Complete $\rightarrow$ Recharge**：
   - 充满后 $V_{bat} \le V_{recharge}$ 持续 **1s**，请求 `request_restart`，清零 MPPT/Duty 重新进行准入。

## 3. 真实功率传输时间累计

- 最大充电总时长 **900min**（`AURORA_MAX_CHARGE_TIME_MS`）与浮充 **180min** 仅在 `actual_power_transfer == true` 时累计；
- 必须同时满足：`Battery模式` + `RUN` + `Relay闭合` + `物理PWM发波` + `Charger许可` + `Ppv >= 1000mW`。
- 启动等待、零点校准、继电器均压及无光等待时间不计入。

## 4. 铅酸温度补偿

- **基准温度**：25°C（`AURORA_LEAD_TEMP_COMP_REFERENCE_DC = 250`）；
- **补偿系数**：$-3\text{mV}/^\circ\text{C}/\text{cell}$（48V=24格，60V=30格，72V=36格）；
- **环境温度钳位**：$-20^\circ\text{C} \sim +55^\circ\text{C}$；
- **防撞顶保护**：低温温补提升的 CV 目标受 $(V_{ov\_fast} - 500\text{mV})$ 钳制，防止温补后撞上 3ms 快速软件过压保护；
- 补偿同步更新 CV、Float、Full 及慢/中速软件过压阈值。

## 5. 无 BAT_I 硬件下的 CC 控制

- 电池电流采用前馈 + 估算修正：
  $$P_{bat\_target} = V_{bat} \times I_{target} + \text{PI}(I_{target} - I_{bat\_est})$$
  $$P_{pv\_allow} = P_{bat\_target} / \eta$$
- 分段效率 $\eta$ 取 85%（<20W）、90%（20~100W）、92%（>100W）；
- 电池侧所有电流与能量数据均显式保留 `ESTIMATED` 语义。
