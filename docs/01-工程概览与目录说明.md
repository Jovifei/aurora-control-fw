# 01 · 工程概览与目录说明

## 1. 产品与硬件边界

当前硬件是单路异步Boost：只有低侧储能MOS的 `GLC` PWM，放能依靠并联二极管；PA14/GHC在原理图上有网络但未接到功率管，保持GPIO低。电池电流由 `PV_U × PV_I × 效率 / BAT_U` 估算，并始终带 `ESTIMATED` 质量标记。

默认高功率BOM，通过 `AURORA_POWER_PROFILE` 可切换低功率BOM。两种功率档共用同一套业务代码，不能复制两套状态机。

## 2. 唯一目录

```text
app/
├─ inc/      业务模块公共头、统一类型、应用参数和运行时接口
└─ src/      业务模块、应用入口、ISR桥接和Debug实现
driver/
├─ inc/      每个驱动模块对应的头、公共契约和板级配置
└─ src/      G32F031外设及板级驱动实现
vendor/      目标构建所需芯片库
project/     Keil AC6工程、scatter和用户工程配置；目标入口与ISR位于app/src/
docs/        文档与原理图，不放生产.c/.h/JSON
tests/       Host模拟驱动与回归测试，不进目标镜像
tools/       架构、代码规范、编译、Sanitizer和目标语法门禁
```

以下内容已经删除且不得恢复：

```text
firmware/
tasks/
.bootstrap/
legacy_reference/
legacy_parity/
legacy_protocol_import/
app/中的arm_*厂商文件
生成JSON
重复的tests/tools/docs
```

## 3. APP功能模块

| 模块 | 主要职责 |
|---|---|
| main | 系统运行根、调度编排、能量累计、设置切换、协议命令落地、PWM最终安全复核与门禁执行 |
| interrupts | 中断向量桥接、快速关波、消音与轻量事件投递（禁止重业务） |
| debug | GE_DEBUG日志输出及编译期模块开关 |
| measurement | DMA完整块去极值、标定、物理量快照、BAT_I估算、PV_I零点校准、NTC换算 |
| mppt | Voc初始化、P-V斜率搜索、自适应步长、Vref PI和理论功率请求 |
| charger | 12组电池档案、TC/CC/CV/Float状态机、铅酸温补、多体系低温禁充 |
| protection | 软件多级保护、去抖、active/latched故障管理与安全epoch |
| power_stage | 启动退避、零点准入、电池识别、预充升压、继电器时序、Duty执行器、Demo模式与故障恢复 |
| ui | RUN/FAULT指示相位与故障分组闪烁编码 |
| protocol | 产品UART协议解析、帧编解码与1s主动遥测 |
| storage | 双页Flash Journal v3（兼容v1/v2）、两阶段Commit Marker与双能量历史持久化 |

## 4. 为什么保留tests和tools

- `tests/`验证算法、协议、Flash、预充起步、故障重授权、温度隔离、DMA覆盖和看门狗健康窗口；
- `tools/`阻止APP越层、错误PinMap、PWM多出口、运行期软件UPDATE、缺函数头注释、Tab、迟到static、旧源码回流，并运行GCC/Clang/Sanitizer/目标语法检查；
- Keil工程只编译 `app/src`、`driver/src`、`vendor` 和 `project`，不会把tests/tools链接进MCU镜像。
