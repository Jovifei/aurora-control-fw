BOARD_GATE_KEIL_LINKED          = 0
BOARD_GATE_LOW_VOLTAGE_BENCH    = 0

PinMap已经进入代码，但以下必须实测：OPA方向和零点、COMP阈值、U6 EN极性、Break到Vgs关断延迟、ADC采样建立误差、继电器压差窗口和首个GLC脉冲。

## USART路由与日志

PA10/PA11和PB7/PB8是G32F031同一个USART外设的两组复用引脚，不是两个独立串口。路由由`driver/inc/board_config.h`控制：

```c
BOARD_USART_MODE == BOARD_USART_MODE_BLUETOOTH  /* 默认，PA10/PA11 */
BOARD_USART_MODE == BOARD_USART_MODE_DEBUG      /* PB7/PB8，Debug专用 */
```

Debug构建必须同时打开`DEBUG_ENABLE`，日志格式为`[GE_DEBUG][模块] ...`。Debug模式关闭产品协议解析和主动遥测，避免日志与蓝牙数据混流；ISR不直接调用日志函数。

## MOS NTC换算

原理图第9区给出：R37=5.1K上拉、R42=100K 1% 3950 NTC、R39=1K串联、C38=100nF滤波，采样网络接PB12。软件使用ADC码先换算阻值，再按Beta曲线查表插值，范围为-40°C～125°C。R39和C38属于ADC输入滤波网络，不改变直流分压公式。

环境NTC通过CON4接入。原理图只画出板端5.1K上拉/1K串联/100nF滤波，没有在图纸文字中写出外接探头R25/B值；本轮硬件工程师已明确确认**探头未改变，与MOS温度探头采用相同100K/B3950温度特性**。因此两路均使用同一166点R-T表，PB5正式参与环境温度、环境高低温保护和铅酸温度补偿。
