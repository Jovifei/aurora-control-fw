# 13 · 硬件引脚与外设绑定

本表以 `14-REF-硬件原理图-V0.1.pdf` 为当前唯一板级基线。

| MCU引脚 | 网络/用途 | 软件绑定 |
|---|---|---|
| PA0 | OPA0_O | MOS电流内部OPA输出 |
| PA1 / PA2 | OPA0_N / OPA0_P | MOS分流差分输入 |
| PA3 / PA4 / PA5 | OPA1_P / OPA1_N / OPA1_O | PV电流OPA |
| PA7 | COMP0_P | MOS过流参考输入 |
| PA8 | PV_I | ADC CH1 |
| PA9 | PV_U | ADC CH2 |
| PB0 | BAT_U | ADC CH3，外部电池侧 |
| PB1 | BST_U | ADC CH4，继电器前Boost母线 |
| PB2 / PB6 | COMP2_N / COMP2_P | PV快速过流比较器 |
| PB12 | NTC_MOS | ADC CH5 |
| PB5 | NTC_AMB | ADC CH6 |
| PA10 / PA11 | UR_TX / UR_RX | 115200 8N1 |
| PA12 | LINK | 高低电平控制输出 |
| PA13 | RELAY | 继电器，高有效 |
| PA14 | GHC | 当前异步板不使用，保持安全低 |
| PA15 | GLC | AF3 / ATMR_CH0 单路PWM |
| PB7 / PB8 | DEBUG_TX / DEBUG_RX | 调试接口预留 |
| PB9 | LED_RUN | 低有效 |
| PB10 | COMP0_O | AF7，开漏，外接U6 EN |
| PB11 | LED_FAULT | 低有效 |
| PB3 / PB4 | SWCLK / SWDIO | 调试保留 |

## 仍保持关闭的硬件门禁

```c
BOARD_GATE_COMP_ROUTE_VALIDATED = 0
BOARD_GATE_ANALOG_CALIBRATED    = 0
BOARD_GATE_KEIL_LINKED          = 0
BOARD_GATE_LOW_VOLTAGE_BENCH    = 0
BOARD_POWER_OUTPUT_ALLOWED      = 0
```
