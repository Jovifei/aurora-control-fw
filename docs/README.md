## 不可破坏的继电器顺序

`PRECHARGE`期间Relay必须OFF，先受限Boost把BST_U充到接近BAT_U；压差连续稳定后先停PWM，Service在真正写Relay GPIO前再次检查最新压差和故障，之后才能吸合Relay。Relay后还要保持PWM OFF完成10s电池稳定性验证。

当前人工总门：

```c
BOARD_POWER_OUTPUT_ALLOWED == 0
```
