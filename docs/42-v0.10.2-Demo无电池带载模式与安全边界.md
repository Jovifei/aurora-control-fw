# v0.10.2 Demo 无电池带载模式与安全边界（v0.10.3 勘误）

> 文件名保留 v0.10.2，是为了保存功能引入历史；本页的“当前实现”以 v0.10.3 分支为准。v0.10.3 修复了 Demo Relay 被 Battery 条件拒绝、Relay 未落实却继续进入 Probe，以及 Demo 功率可被协议放大到额定功率的问题。

## 1. 模式定位

Demo 是独立运行模式：

```c
AURORA_MODE_BATTERY
AURORA_MODE_DEMO_LOAD
```

它不占用 48V/60V/72V 电池平台枚举，也不恢复按键选档；模式由协议设置并在安全停机窗口生效。

当前硬件没有输出电流传感器，因此 Demo 只能提供：

- 输出电压闭环；
- PV 输入电流与输入功率限制；
- MOS/环境温度保护；
- BUS 过压与 ADC 饱和保护；
- 空载、负载移除和过载退出。

不能宣称具备真实输出恒流、任意负载供电、电池模拟器或持续短路输出能力。

## 2. v0.10.3 启动流程

```text
等待 PV
→ PV_I 零点校准
→ 检查输出端是否存在外部有源电压
→ RELAY_HOLD_OFF：PWM 命令关闭、Relay 保持断开
→ 等待 20ms 放能窗口
→ 等待至少一份更新的 ADC 快照
→ Runtime 按 Demo 专属条件复核
→ 写出 Relay GPIO
→ PowerStage 看到 relay_applied=true 后才开始 100ms 机械稳定
→ 5W 低功率主动 Probe
→ 持续负载成立后进入受限 Demo RUN
```

Demo Relay **不复用** Battery 的 `BST_U≈BAT_U` 均压条件。闭合前至少要求：

```text
Operating Mode == DEMO_LOAD
PWM 物理关闭
无 pending / active / latched 故障
BAT_U 输出端不高于 5V 外部有源检测阈值
BST_U 有效、未饱和且闭合前不高于 5V 低风险阈值
Demo 独立台架门与总功率门均允许
```

`relay_applied` 只表示 Runtime 已把 Relay GPIO 命令写出，不代表机械触点已经闭合。触点路径仍通过 100ms 等待、BUS 行为和后续 Probe 间接验证。

## 3. 不可绕过的 30W 硬顶

v0.10.3 定义：

```c
AURORA_DEMO_HARD_POWER_CAP_MW = 30000U
```

三层限制同时存在：

1. **协议写入**：`power_mw == 0` 或 `power_mw > 30000` 返回 `INVALID`，不提交设置；
2. **旧 Flash 数据**：读取到 `demo_power_limit_mw > 30000` 时钳制为 30W，并安排下一安全窗口重写；
3. **运行时输出**：PowerStage 与应用功率限幅再次 `min(..., 30000)`，防止配置或迁移异常绕过。

因此“默认 30W但协议可配置到 300W”只适用于 v0.10.2 历史审计，不再是 v0.10.3 当前事实。

## 4. Probe 与运行边界

### 4.1 Demo Probe

- 探测输入功率上限：5W；
- PV 输入功率达到约 2W 并持续 1.5s，才认为存在持续负载；
- 5s 内无法建立负载证据，进入无负载停止；
- 输出端存在外部有源电压、BUS 测量无效或过载时立即退出。

### 4.2 Demo RUN

- 默认目标 48V；
- 最大允许目标 58V；
- 输入功率硬顶 30W；
- 无输出电流传感器，所谓“过载”只能由输入侧功率、电流、BUS 电压和状态变化间接判断；
- 负载移除、输出失控、BUS 过压、温度或其他 Protection 故障均撤销 PWM。

## 5. 当前硬件限制

Relay 断开时，BAT_U 无法区分“完全空载”和“接了无源负载但尚未供电”。当前实现只能使用低能量主动探测，并且只适用于经过台架确认的负载类型。

产品化建议增加至少一种硬件能力：

- Relay 跨接预充电阻与受控开关；
- 小电流输出探测源；
- 输出电流传感器；
- 适合带载探测的固态开关；
- Relay 辅助触点或等价路径反馈。

纯电容、阻性负载、电子负载、突然卸载、外部电源误接和短路必须保留为实板验收项目。

## 6. 门禁与发布边界

```c
BOARD_GATE_DEMO_LOAD_VALIDATED == 0
BOARD_POWER_OUTPUT_ALLOWED     == 0
```

运行层通过 `drv_board_demo_load_gate_open()` 读取 Demo 台架门，且只在 `AURORA_MODE_DEMO_LOAD` 下与总功率门一起复核。不得把 Demo 门并入 Battery 模式的公共准入逻辑。

当前准确状态是：

```text
DEMO SOFTWARE PATH IMPLEMENTED
30W HARD CAP ENFORCED
RELAY HANDSHAKE IMPLEMENTED
REAL LOAD MATRIX NOT VALIDATED
PHYSICAL POWER GATES LOCKED
```

在 Demo 负载矩阵、Relay 波形、COMP/Break、模拟标定和低压功率台架完成前，Demo 只能作为软件候选功能。
