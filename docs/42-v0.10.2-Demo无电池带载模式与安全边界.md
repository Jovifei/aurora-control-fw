# v0.10.2 Demo 无电池带载模式与安全边界

## 1. 模式定位

Demo 是独立运行模式：

```c
AURORA_MODE_BATTERY
AURORA_MODE_DEMO_LOAD
```

它不占用 48V/60V/72V 电池平台枚举，也不恢复按键选档；模式由协议设置并在安全停机窗口生效。

## 2. 当前控制能力

当前硬件没有输出电流传感器，因此 Demo 只提供：

- 输出电压控制；
- PV 输入电流限制；
- PV 输入功率限制；
- MOS/环境温度保护；
- BUS 过压与 ADC 饱和保护；
- 空载、负载移除和过载退出。

不能宣称具备真实输出恒流能力。

## 3. 启动流程

```text
等待 PV
→ PV_I 零点校准
→ 检查输出端是否已有外部有源电压
→ PWM 关闭状态下连接 Relay
→ 低功率主动探测
→ 确认存在持续负载
→ 进入受限 Demo RUN
```

输出端已有明显电压时，视为可能误接电池、适配器或其他有源设备，禁止 Demo 启动。

## 4. 退出条件

以下任一情况均撤销 PWM 并退出：

- 无持续负载；
- 纯电容充电结束后功率降到空载区；
- 负载突然移除；
- 输出电压失控；
- PV 输入电流或功率达到限制；
- BUS 过压、BUS ADC 饱和；
- 温度或其他 Protection 故障。

## 5. 当前硬件限制

Relay 断开时，BAT_U 无法区分“完全空载”和“接了无源负载但尚未供电”。因此当前版本使用低能量主动探测，且只适用于经过台架确认的负载类型。

产品化建议增加至少一种硬件：

- Relay 跨接预充电阻与受控开关；
- 小电流输出探测源；
- 输出电流传感器；
- 适合带载探测的固态开关。

## 6. 门禁

```c
BOARD_GATE_DEMO_LOAD_VALIDATED == 0
BOARD_POWER_OUTPUT_ALLOWED == 0
```

运行层通过 `drv_board_demo_load_gate_open()` 读取 Demo 台架门，且只在 `AURORA_MODE_DEMO_LOAD` 下与总功率门一起复核。不得把 Demo 门并入 `drv_board_power_gate_open()`，否则 Battery 模式也会被未完成的 Demo 验收卡住。

在 Demo 负载矩阵和 Relay 波形验收完成前，Demo 只能作为软件候选功能。
