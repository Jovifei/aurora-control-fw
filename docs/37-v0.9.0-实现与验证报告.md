# 37 · v0.9.0 实现与验证报告

本版本目标是把300W 3.3V模拟采样链和旧120W成熟时间行为对齐，同时不改变v0.8.1 PVD供电资格、v0.8.3两层架构、PWM epoch/Break/preload以及Relay先预充后闭合的安全顺序。

## 已实现

- PV_I默认硬件模型从旧2048/-1偏置假设改为新板0/+1候选，实际零点仍由运行时校准。
- PV_I零点增加单块spread、连续稳定窗口和最大尝试次数；不稳定块只重启稳定证据，持续失败才阻止启动。
- NTC继续使用旧166点100K/B3950表；修正Open/Short物理方向；增加方向滤波。
- BST_U ADC近满量程直接撤销有效位并锁存独立故障，禁止Relay误吸合。
- 铅酸恢复25°C/-3mV°C/cell温补，并增加Fast OV安全钳制。
- 恢复TC/CC/CV/Float/Recharge成熟时间行为。
- 恢复PV_I运行/停机合理性诊断，并明确只有运行时零点校准完成后才启用，避免启动前理论零点误报。
- 恢复13V/15V启动门槛的100ms连续资格确认，弱光临界抖动不会单点触发启动。

## 有意未改

- v0.8.1 MCU PVD弱光启动。
- Relay：BST_U先Boost预充→压差稳定→PWM OFF→二次复核→Relay ON→BAT_U稳定10s→RUN。
- 无BAT_I估算属性。
- 95°C降额起点。
- 功率总门保持0。
- 没有复制旧实现的具体滑动数组，但已恢复等价的100ms连续PV启动资格门；MPPT闭环仍使用快速DMA快照。
- 真24h能量和BAT反向电流保护继续作为已知差异，不做虚假等价实现。

## 验证

以本分支最终GitHub Actions `Firmware quality gates`为软件验证证据。Host/Clang通过不等于Keil AC6或实板安全验收。
