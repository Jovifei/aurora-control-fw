## 4. 你下一步真正应该做什么

建议按下面顺序补**板级证据**，不要从G6直接开始发PWM。

### Step 1：关闭 G0

必须完成：

```text
[ ] 人工确认当前原理图/BOM/PinMap为唯一基线
[ ] PA15/GLC、PA14/GHC、PA13/RELAY、PA12/LINK通断正确
[ ] ADC六通道对应焊盘与网络正确
[ ] OPA1_O(PA5)→PV_I ADC路径按实板/图纸确认
[ ] PB1=BST_U，不与COMP2误混
[ ] D2/D3、L3、MOS、Relay方向/型号确认
[ ] 无异常低阻/短路
[ ] 记录PCB/BOM版本并回填G00 RESULT
```

**通过条件**：G00 RESULT可从`IN_PROGRESS`改为`BOARD_PASS`或至少明确签字通过硬件腿。

---

### Step 2：关闭 G1

只运行最小安全工程，不启动ADC/PWM/COMP功率能力。

测试：

```text
[ ] 上电瞬间 PA15/GLC 无未知高脉冲
[ ] PA14/GHC 始终LOW
[ ] Relay始终OFF
[ ] LINK符合安全态
[ ] NRST复位期间同样无功率脉冲
[ ] HardFault路径先强制功率脚安全再停机/复位
[ ] RUN灯/1ms节拍行为正确
```

示波器重点同时观察：

```text
CH1: NRST
CH2: PA15/GLC
CH3: PA14/GHC
CH4: Relay
```

**失败时禁止进入任何PWM测试。**

## 7. 当前仍需重点关注的硬件风险

### BST_U量程

当前26:1 + 3.3V ADC理论满量程约85.8V。

因此72V高SOC/CV/OV区域仍可能超量程。软件近满量程保护只能拒绝不可信读数，**不能恢复已经饱和的信息**。

在G9/72V高压测试前必须冻结硬件ECO决策。

### BAT_U高源阻抗

15M/510k分压源阻抗较高，必须用实板验证ADC采样时间与建立误差，不能只按理论系数判断。

### 无BAT_I

当前没有真实电池电流采样：

```text
Ibat
电池侧功率
尾流
电池侧能量
```

均只能估算。G12/G15必须用外部功率分析仪/电池模拟器对比。

### 300W定义

在G15前必须明确：

```text
300W = PV输入额定？
300W = 电池侧连续充电？
300W = 瞬时/器件能力？
```

当前12A PV限流和各档约3A充电目标决定了“所有输入/所有电池档位都连续300W”并不自动成立。


