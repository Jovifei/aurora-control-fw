# 08 · 继电器预充与无发电断开

## 1. 继电器绝对安全闭合顺序

为防止高压差合闸打火拉弧损坏继电器触点或造成母线大电容冲击，系统在启动时严格执行以下不可逆安全时序：

```text
Relay 初始保持 OFF
   ↓
PRECHARGE：受限 Duty 开启 Boost 提升 BST_U 母线电压（上限 30s）
   ↓
|BST_U - BAT_U| <= 1.5V 连续保持 1.0s（AURORA_RELAY_DELTA_HOLD_MS）
   ↓
软件 Duty 归 0，功率积分清零
   ↓
运行层（main.c）执行 force_safe_off() 物理关断 PWM
   ↓
relay_close_still_safe() 实时二次复核（PWM确认无输出、压差再次达标）
   ↓
drv_io_set_relay(true) 物理吸合继电器
   ↓
RELAY_SETTLE：等待 100ms（AURORA_RELAY_SETTLE_MS）机械稳定
   ↓
复核压差 |BST_U - BAT_U| <= 2.5V（AURORA_RELAY_VERIFY_DELTA_MV）
   ↓
BAT_STABILITY：PWM 保持关闭，完整观察 BAT_U 10s（max - min <= 2.0V）
   ↓
进入 RUN 正式 MPPT 充电
```

## 2. 预充异常与母线保护

1. **相对过冲保护**：预充过程中若 $BST\_U > BAT\_U + 2.5\text{V}$（`AURORA_BUS_RELATIVE_OVERSHOOT_MV`），立即终止预充并锁存 `AURORA_FAULT_BUS_OVERVOLT`（硬锁死）；
2. **预充超时**：若 30s（`AURORA_PRECHARGE_TIMEOUT_MS`）内无法满足压差条件，判本次启动失败，最多重试 3 次；
3. **ADC 近满量程防呆**：BST_U ADC 原始码达到 $\ge 4080$ 时视为量程不可信，**撤销母线测量有效位**，继电器闭合门禁自动拒绝通过。

## 3. 真正无发电 30 分钟断开逻辑

- **判定条件**：
  $$V_{pv} < 13.0\text{V} \quad \text{AND} \quad \text{MPPT 未运行/无效}$$
- **时序行为**：
  - 满足上述条件连续保持 **30 分钟**（`AURORA_NO_SUN_OPEN_RELAY_MS = 1,800,000ms`）；
  - 先停止 PWM，再断开继电器（`relay_closed = false`），进入 `NO_SUN` 待机状态；
  - 电池充满（Complete 阶段）但太阳仍在时**不触发** 30min 关机计时。
- **恢复唤醒**：PV 电压恢复到 $\ge 13.0\text{V}$ 连续稳定 100ms 后，自动回到 `WAIT_PV` 重新开始完整准入流程。

## 4. 故障释放与 20ms 放能窗口

- 快速故障触发时，PWM 必须在 ISR 内**瞬时物理关断**；
- 物理继电器保持 **20ms 放能窗口**（`AURORA_RELAY_FAULT_RELEASE_MS`）后再行断开，确保主电感储能完全泄放完毕，避免在带重载电流时拉弧烧蚀触点。
