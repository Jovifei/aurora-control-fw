# 32 · 120W与300W模拟采样硬件对比

## 1. 结论

旧120W模拟域由HT75R50-1提供约5V VDDA；300W新板G32F031的ADC/内部OPA/COMP和NTC上拉统一使用HT75R33-1产生的约3.3V VDD。电压参考改变后，必须逐条看采样拓扑，不能把旧ADC码和偏置直接移植。

## 2. 通道对比

| 通道 | 120W | 300W | v0.9.0处理 |
|---|---|---|---|
| PV_U | 75k/3k | 75k/3k | 比例26不变，55V约2.115V |
| BAT_U | 旧比例 | 15M/510k | 比例约30.41；93V约3.06V，需实板标定 |
| BST_U | 无同等Relay前独立量 | 125k/5k | 比例26；3.3V满量程仅约85.8V，列P0硬件风险 |
| PV_I | 外置OPA+VDDA/2偏置 | 3mΩ×内部OPA16倍，AVDD/2中点偏置 | zero名义2048码、极性候选+1，启动时32块校准 |
| NTC | 5.1k+100K/B3950，参考5V | 5.1k+100K/B3950，参考3.3V | 电阻/ADC比值不变，沿用166点表 |

## 3. PV_I理论量级

新板理论：`Vopa = 1.65V (AVDD/2) + Ipv × 3mΩ × 16`。12bit/3.3V下约16.79mA/code，零电流名义码约2048，12A约对应增加715code（约2763码）。启动时必须在PWM/Relay关闭下执行运行时零点校准。

## 4. 证据边界

上述硬件数值来自两版原理图。实际OPA极性、ADC参考误差、BAT_U高阻分压误差和BST_U高压行为仍以实板为准，`BOARD_GATE_ANALOG_CALIBRATED`和功率总门继续保持0。
