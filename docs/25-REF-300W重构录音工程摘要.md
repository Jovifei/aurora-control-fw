# 25 · REF · 300W重构录音工程摘要

> 来源：用户提供的 `新录音 8.m4a`。
>
> 本文是工程方向摘要，**不是逐字转写**。录音用于确定300W重构思路；精确保护/充电数值以120W V2.7 Checklist和最终原理图为依据。

## 1. 重构目标

300W版本不是把120W源码整包换MCU，而是保留成熟产品行为，重新建立可移植的软件层次：

```text
ADC定时触发/多通道DMA
        ↓
Measurement物理量快照
        ↓
Protection / Charger / MPPT
        ↓
Power Stage
        ↓
Service最终安全仲裁
        ↓
Driver / PWM / Relay
```

## 2. 新硬件必须接受的事实

- 当前功率级是单路异步Boost，只使用GLC低侧PWM，不恢复旧同步MOS逻辑；
- 没有BAT_I独立采样，电池电流只能由PV功率、效率和BAT_U估算，必须标识`ESTIMATED`；
- 使用内部比较器和ATMR Break形成快速硬件关波链；
- 参数存储改为片内Flash；
- 默认300W，高/低功率BOM通过编译Profile区分；
- MPPT使用自研算法，不依赖HT32闭源库。

## 3. MPPT职责

MPPT只决定PV应该工作在哪个电压/功率区域，不直接写CCR：

```text
PV V/I/P
→ P-V斜率搜索更新Vpv_ref
→ PV参考电压PI产生理论PV功率请求
→ Charger/温度/PV电流/额定功率形成最终包络
→ Power Stage把功率命令转换为物理Duty
```

## 4. 继电器是300W启动链的硬约束

录音描述与本轮用户再次确认一致：必须先用Boost给继电器前母线BST_U充电，等BST_U与BAT_U接近后再吸合继电器。v0.8.0把它固化为：

```text
Relay OFF
→ 受限Boost给BST_U充电
→ |BST_U-BAT_U|<=1.5V连续1s
→ Duty归0，物理关PWM
→ Service再次核对最新BST_U/BAT_U和故障
→ Relay ON
→ 100ms后复核压差<=2.5V
→ PWM继续OFF观察BAT_U 10s，波动<=2V
→ RUN
```

这条顺序优先级高于普通充电状态机或MPPT请求。

## 5. 与120W的关系

120W工程提供：电池化学体系、TC/CC/CV/Float、保护时间、启动退避、Link/LED等成熟产品行为。

300W工程重新定义：硬件驱动、功率能力、无BAT_I后的电池侧估算、单路PWM、内部比较器、继电器预充和可移植架构。

因此不得把“行为继承”误写成“旧源码继续运行”，也不得把120W的8A/120W/热降额绝对功率值直接按比例放大。
