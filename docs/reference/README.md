# Reference Inputs

本目录保存v0.8.0行为迁移所需的工程化参考资料，不保存旧HT32源码或闭源MPPT库。

## 原始输入

- 用户提供：`青稞120W MPPT保护功能CheckList_V2.7_20260824.xlsx`。
- 该原始表格是120W成熟产品行为与参数的权威来源；为避免在仓库中重复保存用户原始二进制，本仓库不复制该原始文件。
- 如本文、派生表格或代码注释与原始V2.7表格发生冲突，应回到用户提供的原始表格重新核对，不允许自行用通用经验替代。

## 仓库内派生资料

- `120W_to_300W_Protection_Charge_Migration_v0.8.0.xlsx`：从原表整理出的保护基线、12组电池档案、300W候选值、迁移矩阵和待确认/台架项。
- `../22-REF-120W-V2.7行为与参数基线.md`：面向代码审查的120W行为摘要。
- `../23-120W到300W行为迁移矩阵.md`：区分原样继承、参数重算、新硬件等价替代和旧功能删除。
- `../25-REF-300W重构录音工程摘要.md`：用户录音中的300W重构方向摘要，不作为精确阈值来源，也不是逐字转写。

## 证据优先级

1. 用户提供的原始V2.7 Checklist；
2. 最终原理图及用户确认的300W硬件事实；
3. 本目录派生迁移表；
4. 工程Markdown摘要和源码注释。

300W的PV基础限流、过功率边界以及95~104°C降额功率曲线仍需实物台架最终冻结，不能因为Host/CI测试通过而视为已验证硬件参数。
