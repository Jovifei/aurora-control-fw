# 35 · v0.9.0 BST_U量程风险与硬件整改门禁

## 1. 发现

300W最新原理图的BST_U为125k/5k，分压比26。G32F031 ADC参考约3.3V，因此系统侧理论满量程约 `3.3 × 26 = 85.8V`。

| BST_U | ADC脚理论电压 | 结论 |
|---:|---:|---|
| 82.2V | 3.162V | 尚在3.3V内 |
| 85.8V | 3.300V | 理论满量程 |
| 87.2V | 3.354V | 超参考，可能饱和 |
| 93V | 3.577V | 明显超参考 |

72V高SOC档案会进入这一风险区域，而Relay安全链依赖BST_U与BAT_U实时压差，因此必须按P0处理。

## 2. 软件Fail-safe

- BST_U raw进入近满量程时设置`AURORA_MEAS_DIAG_BUS_ADC_SATURATED`。
- 不再置`AURORA_MEAS_VALID_BUS_V`。
- Protection锁存`AURORA_FAULT_BUS_ADC_SATURATION`。
- Power Stage因缺BUS有效位停止推进；运行层Relay二次复核也必然拒绝闭合。

因此软件不会把一个饱和的BST_U值误认为“BST_U≈BAT_U”。

## 3. 硬件待确认

软件不能通过改比例系数恢复已经在ADC脚饱和的信息。硬件需要重新评估BST_U分压和最高工作电压余量。若希望93V对应ADC不高于约3.0V，比例需约>=31；若希望接近100V仍保留余量，比例约>=33.3。这里仅给出量程关系，不指定最终阻值。

## 4. 门禁

在硬件确认、ADC标定和Relay四通道波形验收前：

```c
BOARD_GATE_ANALOG_CALIBRATED = 0
BOARD_GATE_LOW_VOLTAGE_BENCH = 0
BOARD_POWER_OUTPUT_ALLOWED   = 0
```
