# 23 · 120W → 300W 行为迁移矩阵

## 1. 分类规则

| 类型 | 含义 | 处理原则 |
|---|---|---|
| A 原样继承 | 与功率器件能力无关的成熟产品行为 | 参数/状态机尽量保持V2.7 |
| B 结构继承、参数重算 | 逻辑正确，但300W阈值需要重新标定 | 保留分级结构，300W数值标候选 |
| C 新硬件等价替代 | 旧硬件功能不存在，但安全目标仍需实现 | 用新硬件/估算/软件链替代并明确差异 |
| D 删除 | 旧板专有且新板不存在 | 不重新引入 |

## 3. 继电器绝对顺序

本项目后续任何改动都不得破坏：

```text
PRECHARGE：Relay必须OFF
→ Boost先提升BST_U
→ |BST_U-BAT_U| <= 1.5V
→ 连续保持1s
→ 软件Duty先归0
→ Service物理关PWM
→ 才允许Relay ON
→ 等100ms机械稳定
→ 再验证压差<=2.5V
→ PWM保持OFF观察BAT_U 10s
→ 10s内max-min<=2V
→ 才进入RUN
```

如果后续代码出现“先闭继电器、再慢慢拉高BST_U”，应直接判为安全回归。

## 4. 不允许“伪等价”的项目

以下功能新板硬件不存在，文档和代码中不能写成“已完全等价”：

- BAT_I真实ADC；
- BAT_I快速CMP；
- 旧BAT_U硬件过压CMP；
- 同步MOS及互补PWM；
- 旧HT32闭源MPPT库。

300W代码必须清楚标出估算、软件替代和未闭环硬件风险。
