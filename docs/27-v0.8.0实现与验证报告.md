- 12组电池档案按V2.7重新录入，充电目标与保护阈值分离；
- 铅酸CV目标58.0/72.5/87.0V，Float目标54.6/68.3/82.0V，Float结束80mA；

- Link和两LED故障分组行为按V2.7适配。
