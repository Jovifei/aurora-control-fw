# 33 · NTC采样计算与5V到3.3V迁移原理

## 1. 为什么温度曲线不因5V→3.3V而改变

两版原理图都采用：VREF/VDD → 5.1k → ADC节点 → 100K NTC(B3950) → GND，且ADC参考与上拉同源。

`ADC = 4095 × Rntc / (5100 + Rntc)`，供电电压在比值中约掉。因此旧120W的100K/B3950、-40~125°C共166点阻值表可以继续使用。25°C时R≈100K，理论ADC约3897。

## 2. 开路/短路物理方向

- NTC开路：下拉消失，ADC被5.1k拉向VDD，raw接近4095。
- NTC短路：节点被拉向GND，raw接近0。

v0.8.3以温度端点命名Open/Short方向相反；v0.9.0改为先按raw判断物理状态，只有OK才做阻值/温度查表。

## 3. 温度滤波

继承旧120W的方向确认思想：每10ms观察一次，连续10次同方向变化才更新控制温度，主要避免95°C降额边界附近抖动。Open/Short状态不经过该慢滤波，仍由Protection的1s故障确认处理。

## 4. 铅酸温补

环境NTC有效时，铅酸按25°C基准、-3mV/°C/2V cell、-20~55°C钳位进行温补。新平台额外限制正向低温补偿不得把CV上限逼近固定Fast OV层。该安全钳制属于300W平台适配，不是旧源码原值。
