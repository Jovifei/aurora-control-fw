# 36 · v0.9.0 参数与台架确认清单

## P0

1. BST_U 125k/5k量程是否修改；验证85~93V区间ADC脚波形。
2. PV_I内部OPA×16方向：确认正向PV电流是否raw上升。
3. PV_I 3mΩ×16实际增益、零点、温漂、单块spread、连续窗口spread和最大尝试次数。
4. BAT_U 15M/510k高源阻抗下的静态误差、ADC漏电/建立时间。
5. NTC_MOS/NTC_AMB 5.1k、100K/B3950实际25°C/端点实测。
6. 弱光13V/15V附近反复扫输入，确认100ms资格门能过滤临界抖动且最终光照增强后自然启动。
7. Relay：BST_U/BAT_U/GLC/Relay四通道，确保任何BUS饱和/失效都不会吸合。

## P1

1. 铅酸环境NTC位置是否可代表电池温度；若不能，只能把温补作为产品温度代理并限定范围。
2. 95~104°C 300W降额曲线。
3. PV_I合理性阈值-1A/3A/0.5A是否适合新板噪声和偏置。
4. CC估算电流PI、效率分段。
5. 2.8V PVD弱光启动门限继续与3.2V对比。

## 仍不伪装完成

- 无BAT_I，不能复刻老板µs级电池反向电流保护。
- 真24h滚动发电量需要内部Flash磨损均衡方案，v0.9.0只记录缺口。
- Keil AC6真实链接、MAP和板级功率验证仍需本地完成。
